## A. Конструктор программ с синком (Фичи #2) — крупнейшая часть

- **ИСПРАВЛЕНО (критично):** `sessions.template_id` сейчас `VARCHAR(8)` (`db/schema.sql:8`) —

## B. Авто-прогрессия нагрузки (Фичи #3)

**data.js**:
- `stepKg(name)` → 5 для ног (ключевые слова: присед/носк/ног/выпад/гоблет/икр), иначе 2.5.
- `lastExerciseSets(sessions, name)` → подходы из самой свежей сессии с этим (canon) упражнением.
- `suggestForm(tpl, sessions)` — как `initForm`, но веса/повторы по каждому упражнению
  предзаполняются из последней тренировки (по совпадению canon-имени); при отсутствии истории —
  дефолты шаблона.
- **ИСПРАВЛЕНО (разделение ответственности):** мета для чипа вынесена в отдельный
  `exerciseMeta(sessions, name)` → `{lastText, step}` (`lastText` = «80×5 / 80×5 …»),
  а `suggestForm` возвращает только форму. Чип читает мету.

**App.jsx / Log**:
- `pick(id)` (`:299`), начальный `useState` формы, сброс в `commit`/`cancelEdit` — через
  `suggestForm` вместо `initForm`.
- В карточке упражнения формы (рядом с `ft-ex-name`, `:410`) — чип-кнопка `↑ +{step} кг`
  (полный «в прошлый раз {lastText}» в `title`); клик прибавляет `step` к весам всех непустых
  подходов упражнения (через `setForm`). Мету считать `useMemo` от имён упражнений + `sessions`.
- `startEdit` (`:304`) не трогаем — редактирование берёт значения самой сессии.

## C. Личные рекорды — бейдж 🏆 (Графики #1)

**data.js**: `prSessionMap(sessions, bio)` → `Map<sessionId, string[]>`. Идём по сессиям по
возрастанию даты, ведём `best[canonName]` = макс. эффективная нагрузка (`exerciseTop(e, bw)`,
`bw = bodyweightOn(bio, date)`); PR засчитывается только если ранее уже был `best` и текущий
`exerciseTop` строго его превышает (первое появление упражнения рекордом не считаем). `top===0`
(нет данных, в т.ч. BW без веса тела) пропускаем.

**App.jsx**:
- `Log`: `useMemo` `prMap`; в шапке карточки истории (`:470–476`) при наличии записи —
  иконка `Trophy` (lucide) с тултипом-списком упражнений-рекордов.
- `Home`: тот же `prMap`, бейдж 🏆 в карточке «Последняя тренировка» (`:203`).
